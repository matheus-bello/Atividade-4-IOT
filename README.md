# Atividade-4-IOT

Discente: Matheus Bello
Docente: Amanda Paul Dull

Este projeto utiliza um Arduino UNO, dois LEDs e um botão para controlar diferentes estados das saídas.
#Controle de LEDs!
O botão é utilizado como entrada para alternar o estado dos LEDs. Em cada acionamento, o Arduino muda entre LED vermelho, LED azul e ambos desligados.
Botão → pino 6 LED vermelho → pino 10 LED azul → pino 13

Materiais necessários:
1 Arduino UNO
1 Cabo USB
1 placa de prototipagem
2 LEDs
2 resistores
1
Suéter Fios
